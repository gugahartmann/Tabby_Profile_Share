# Authentic Tabby Profile Share screenshots

This folder contains real screenshots of the plugin running in official Tabby, using **synthetic, non-production SSH demo profiles** from `examples/demo-profiles.yaml`.

Expected images:

- `export-overview.png` — export tree, selected devices and opt-in SSH usernames
- `import-overview.png` — import summary and confirmation
- `import-username-prompt.png` — username prompt for demo hosts
- `exported-json-example.png` — portable, sanitized JSON package

Use only screenshots taken with fictional profiles. Never include real network inventory, credentials, private keys or terminal sessions. The PNGs are provided separately to the repository maintainer for upload.

See [the complete guide](../SCREENSHOTS.md).
