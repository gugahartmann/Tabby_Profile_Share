# Short project description and announcement copy

Use the following copy on GitHub, npm, community forums, and social posts. Avoid promises beyond the tested behavior of the plugin.

## GitHub short description (English)

Export, import and share Tabby SSH profiles with nested folders, explicit username sharing and credential-free JSON files.

## npm package summary (English)

Share SSH connection profiles and nested folders between Tabby installations. Select devices, opt in to shared SSH usernames and import without overwriting existing profiles. Passwords, keys and login scripts are excluded.

## Community announcement — English

**Tabby Profile Share** is an open-source plugin for the official Tabby terminal. Select SSH folders or devices, export a portable JSON file and import profiles without overwriting existing entries. Sharing SSH usernames is opt-in; passwords, private keys and login scripts are excluded.

Install in **Tabby → Settings → Plugins**, search **profile-share**.

- npm: https://www.npmjs.com/package/tabby-profile-share
- GitHub: https://github.com/gugahartmann/Tabby_Profile_Share
- Release: https://github.com/gugahartmann/Tabby_Profile_Share/releases/tag/v0.1.4

**Privacy note:** even without credentials, export files may contain sensitive hostnames, IPs and selected SSH usernames; review them before sharing.

## Anúncio curto — Português (Brasil)

**Tabby Profile Share** é um plugin open source para compartilhar perfis SSH e a estrutura de pastas do Tabby. Selecione equipamentos, exporte para JSON e importe sem sobrescrever os perfis existentes. O compartilhamento de usuários SSH é opcional; senhas, chaves privadas e scripts de login ficam de fora.

Instale pelo **Tabby → Settings → Plugins** e procure **profile-share**.

- npm: https://www.npmjs.com/package/tabby-profile-share
- GitHub: https://github.com/gugahartmann/Tabby_Profile_Share

**Atenção:** exports podem conter IPs, hostnames e usernames selecionados; revise antes de compartilhar.
